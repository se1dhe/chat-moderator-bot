# RedQueen Security — Roadmap

> Мастер-документ — [PROJECT_PLAN.md](./PROJECT_PLAN.md). При расхождении верить ему.

Разбивка на релизы. Принцип: сначала паритет базовой модерации и рынок, затем AI и
монетизация. Не «всё в одном коммите» — иначе проверка рынка сильно откладывается.

## Паритет с GroupHelp (что нужно покрыть)

Защита входа (captcha, join-заявки), антиспам, антифлуд, NSFW-фильтр, banned words,
night/silent mode, кастомные команды и автоответы, роли и exemptions, пины, блокировка
sticker/GIF, массовые действия (ban/kick/mute/warn/unban + purge), статистика/тренды/
неактивные, правила и ссылки-приглашения, перевод, бэкап настроек, clone-боты.

## M1 — Каркас и базовая модерация ✅
- Конфиг, БД (Postgres+Alembic), ядро aiogram, DI-мидлвари, ACL-фильтр админа.
- `/start`, `/help`, команды: `ban`, `kick`, `mute`, `unmute`, `warn`, `unwarn`,
  `unban`, `purge`.
- Warn-система с порогом → авто-действие (mute/ban) и активными/погашенными варнами.
- Настройки чата (JSON) + аудит-лог всех действий.
- Docker Compose (postgres, redis, ollama, bot), запуск в polling локально.

## M2 — Защита входа и антиспам ✅  ← текущий этап
- Captcha (кнопка/математика), карантин новичков, авто-кик по таймауту (DB-driven
  sweeper), join-заявки через ЛС.
- Антифлуд (Redis fixed-window), блокировка ссылок/форвардов/упоминаний, блок медиа
  по типу.
- Banned words (список), night/silent/slow mode, exemptions по ролям.
- i18n-каркас (EN/RU/UK), онбординг с проверкой прав, `/checksetup`.

## M3 — AI-модерация (киллер-фича)  ← следующий этап
- Ollama+Qwen3.5, очередь анализа, карантин с карточкой решения для админа.
- Категории spam/scam/toxicity/nsfw/flood, порог уверенности на чат.
- Режимы off / quarantine / autoban(Pro). Explainable-логи вердиктов.

## M4 — Монетизация и Mini App
- Telegram Stars: Pro-подписка на чат, ledger платежей, возвраты.
- Mini App: правила, AI-очередь, роли, аналитика; языки EN/RU/UK.
- Freemium-гейтинг фич на уровне чата.

## M5 — Мультимодальность и масштаб
- Vision (изображения/GIF), ключевые кадры видео, ASR голосовых, document extractor.
- Кросс-чат репутация, шаринг чёрных списков, clone-боты, вебхук+ngrok/прод-домен.

## Killer-фичи (дифференциаторы)
1. **Explainable AI quarantine** — карточка решения вместо «тихого бана».
2. **Adaptive trust score** — репутация пользователя копится по поведению, снижает
   трение для «хороших» и ужесточает проверки для подозрительных.
3. **Raid shield** — авто-детект скоординированных наплывов ботов и лок чата.
4. **Мультимодальный анти-скам** — распознавание скам-картинок/голосовых, не только текста.
5. **Локальный приватный AI** — данные не уходят в облако, дёшево масштабируется.
6. **RedQueen-персона** — узнаваемый голос и UX (тема Resident Evil).

## Тема и голос (RedQueen / Resident Evil)
Бот общается как ИИ-система безопасности «Улья»: холодно-вежливо, лаконично.
Приветствие — «You're all going to die down here.» перефразировать в дружелюбный
security-тон. Стартовое сообщение, тексты действий и карточек выдержаны в этом стиле,
но остаются понятными и не токсичными к пользователям.
